AppID：`wx5971d92eb86b0234`

生产 API：`https://www.leanwise.lydiaowo.com`

当前版本提供今日摄入、文字食物解析、照片留存与手动核对、食品营养记忆、常用配方、目标与体重趋势、历史编辑、文本备份和基于个人记录的 AI 顾问。记录使用 `wx.setStorageSync` 保存本机，没有微信登录、跨设备账号或云端记录同步；Web 与小程序的记录互相独立。

## 1. 先完成网站 API 部署

在浏览器打开：

```text
https://www.leanwise.lydiaowo.com/api/status
```

需要有效 HTTPS 证书、HTTP 200，且返回 `configured: true`。服务器部署方式见项目根目录的 `deploy/README.md`。服务未上线或密钥未设置时，小程序仍可手动记录、使用常用食品和配方；AI 解析与顾问会明确显示服务错误。

小程序调用以下接口，与 Web 共用服务：

| 接口 | 方法 | 用途 |
| --- | --- | --- |
| `/api/status` | GET | 检查 AI 配置 |
| `/api/analyze` | POST | 文字及个人食品/配方记忆解析 |
| `/api/advice` | POST | 根据本机饮食、完整度、目标、体重和消耗摘要给建议 |
| `/api/health/demo-sync` | POST | 获取小米/华为演示数据 |

`config.js` 已写入生产域名，不需要填写任何 API 密钥。

## 2. 在微信后台配置

登录 [微信公众平台](https://mp.weixin.qq.com/)，进入对应小程序：

1. 在“开发 → 开发管理 → 开发设置 → 服务器域名”添加 **request 合法域名**：
   `https://www.leanwise.lydiaowo.com`。不要加路径、端口或尾随斜杠。
2. 当前照片只在本机保存，不使用 `wx.uploadFile`，无需为本 Demo 添加 uploadFile 合法域名。
3. 在“小程序用户隐私保护指引”中如实声明实际使用的接口和数据：拍摄/选择照片、剪贴板文字备份、你主动输入的饮食/目标/体重，以及经你同意发送给 AI 服务的数据。微信后台会按当前基础库和接口使用情况列出需声明项，按实际项填写。
4. 说明 AI 服务由 Leanwise 服务器调用 DeepSeek；照片不上传，文字解析发送食物说明和食品/配方记忆，顾问发送本机记录摘要。
5. 不配置微信运动权限或健康厂商授权。当前没有读取微信运动、小米账号或华为账号。
6. 添加你自己的开发者/体验者微信号，才能预览或查看体验版。

本版本第一次使用 AI 时会显示数据发送说明并征求同意。在“历史与备份 → 数据与隐私”可以撤回 AI 同意和清空本机数据。微信系统自身的照片隐私授权仍应按后台隐私指引配置并在真机验证。

## 3. 微信开发者工具导入、预览和上传

1. 安装并登录正式版 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，微信号需有该小程序开发者权限。
2. “导入项目”，选择本项目的 **`miniprogram` 目录**，不要选择 Leanwise 根目录：
   `C:\Users\tairan.xu\Desktop\AIPM\Leanwise\miniprogram`。
3. AppID 填 `wx5971d92eb86b0234`，普通小程序，后端服务选“不使用云服务”。`project.config.json` 已包含 AppID 和工程配置。
4. 点击“编译”，确认首页与“记录 / 顾问 / 目标 / 历史”页面可打开。
5. 保持“校验合法域名、TLS 版本以及 HTTPS 证书”开启。若开发调试临时关闭，**预览与上传验收前重新开启**。
6. 点击“预览”，用开发者微信扫码，在真机验证下方检查项。
7. 点击“上传”，填写版本号（如 `0.1.0`）和说明（如“Leanwise 本机记录 Demo”）。
8. 上传后到微信后台“版本管理”设置体验版、添加体验者。体验版即可使用；正式公开上线还需管理员提交审核并发布，上传并不等于正式上线。

当前工程没有自动上传或发布过微信版本。

## 4. 真机验收

- 手动添加“我的牛奶”：本次 150 ml；营养基准 240 ml；160 kcal、蛋白质 8 g、碳水 11 g、脂肪 9 g。保存后本项应为 **100 kcal、5 g 蛋白质、6.9 g 碳水、5.6 g 脂肪**。
- 开启“另存为常用配方”，命名“咖啡牛奶”；返回首页再次使用，或在记录页只输入“咖啡牛奶”，应从本机配方复用。
- 一次把本次份量改为 200 ml，但关闭“另存为常用配方”；下次复用仍是配方原份量，历史 150 ml 记录保留原值。
- 从食品库添加原牛奶并纠正营养，记住食品后，下次“咖啡牛奶”使用更新后的营养基准。换品牌时写不同的完整名称，保留旧食品。
- 拍照/选相册后能查看照片；无文字时不会声称已经识别图片，可手动添加食品。填入文字后，AI 根据文字而不是照片解析。
- 在目标页保存个人资料、每日目标和体重；重新打开小程序后仍保留，体重图只显示你真实添加的测量。
- 小米/华为同步始终显示“演示/模拟”，未授权任何真实健康账号。切换身体估算与设备演示不修改每日摄入预算。
- 顾问使用已保存记录与当前目标；未标记“饮食已全部记完”的日期按“截至目前已记录”处理。
- 在历史页选日期修改/删除餐食，复制文本备份并恢复。清除小程序缓存会丢失记录，请先备份；照片不包含在文本备份中。
- 手机关闭网络后，可手动记录、保存体重和复用本机配方；AI 请求报错时不会自动保存草稿。

- **不得把** DeepSeek API Key、微信 AppSecret、RSA 上传私钥写进 `config.js`、页面代码或本工程。
- `private.wx5971d92eb86b0234.key` 是小程序代码上传密钥，不是微信登录 AppSecret。正常使用微信开发者工具登录上传不需要把它放进工程。
- 该私钥目前位于本机工程外：`C:\Users\tairan.xu\.codex\secrets\leanwise\private.wx5971d92eb86b0234.key`。如以后使用 CI 上传，通过微信官方 `miniprogram-ci` 在可信服务器上读取；不要上传 GitHub 或打进小程序包。`project.config.json` 额外排除了 `.key/.pem/.env`。
- 当前 DeepSeek 模型的图片请求已被拒绝，所以交付为**拍照留存 + 文字补充 + 手动核对**。没有伪造图片自动识别。
- 小米/华为目前只有演示同步，没有真实账号授权和实时数据接入。
- 本机存储不是云备份；清缓存、换设备或卸载可能导致记录丢失。文本备份包含个人数据，应由你妥善保存。
- 小程序尚未在微信开发者工具真机预览或上传；Node 模拟检查只能验证数据逻辑与 API 参数，不能代替微信平台编译、隐私合规审核及真机权限检查。
